WooCommerce storefront, product grid, and quick checkout blocks designed to complement the ShopApp theme.

== Description ==

ShopApp Blocks provides three dynamic blocks:

* ShopApp Search & Filters
* ShopApp Product Grid
* ShopApp Checkout

The Product Grid supports WooCommerce product queries, responsive columns, numbered pagination, AJAX Load More, sale presentation, and style controls. ShopApp Checkout provides a configurable floating navigation bar and quick checkout drawer.

The blocks retain the existing `shopapp/*` block names so content created before the theme/plugin separation remains compatible.

== Installation ==

1. Upload the `shopapp-blocks` folder to `/wp-content/plugins/`.
2. Activate ShopApp Blocks in WordPress.
3. Insert the blocks from the ShopApp block category.
